ℹ️ Cómo funciona:
  • Se mantiene el formato original del Excel (colores, fórmulas, hojas adicionales)
  • Solo se actualizan las celdas en el rango de datos que configuraste
  • Si agregaste instrumentos/líneas en la base, se insertan filas nuevas
  • El contenido después del rango se desplaza automáticamente
